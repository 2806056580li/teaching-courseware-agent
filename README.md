# 教师课件增强项目

帮助教师在保留原有教学主线的前提下，把已有课件改得更清晰、更丰富，并逐步加入真实可交互的三维演示和分层讲解。目标使用者不限于大学教师，也包括职业教育、基础教育和培训讲师。

当前状态：0.2.0 本地试用版，待老师端验证。包含固定版式生成器、精选资源下载器、原生PPT三维点击演示和离线欧拉角互动备课包；尚不是商业化产品。发布与测试状态以本仓库实际文件和TEST_REPORT为准。

## 已有成果与限制

- 第二章全章按老师原稿制作，原稿保留本地。34个内容页，含三维姿态重复后为38张物理页；教师仍需复核数学约定。
- 原生 GLB 模型可在编辑视图自由旋转，放映中采用点击逐步旋转并停留，不是任意鼠标拖转。
- `cv-courseware` 提供六种固定版式、JSON 校验、Office 环境诊断、资源下载和预览导出，不依赖 Codex 专用运行时。
- 精选资源覆盖绪论、几何、特征提取、标定、立体视觉、结构光和纹理方向，深度学习仅作补充。109个可下载条目约6.1 MB，含许可证；不是全部库、数据集或训练权重。
- 新增欧拉角备课包：统一生成离线HTML、PPT输入、学生学习包及Agent辅导入口。支持直观/标准/深入解释与课前检查题，不自动认定学生水平，不含在线作业或MCP服务。WorkBuddy 的真实教师环境待验证。

老师原始课件、改造后的课件、联系方式、学生数据和凭证不纳入此次 GitHub 同步。

## 本轮讨论重点

1. 保留老师的教学主线，把排版、图解和素材匹配做可靠。
2. 把静态三维配图升级为真正可拖动、缩放和复位的演示。
3. 以同一个知识点为单位，设计直观入门、标准理解、专业深入三种讲解层次。
4. 将课前检查作为教师选择讲解深度的参考，而不是对学生进行固定分层。

先用欧拉角小样验证“同一备课包、多种输出”的流程。仅这一主题有固定互动组件；不开发完整学生平台、在线作业系统、收费系统或跨学科大规模资源库。

## 仓库管理

本项目使用私有仓库。第三方代码、模型、教材和图片分别保留来源记录，不能仅凭某个仓库的代码许可证推断其中全部素材的使用权限。

项目代码的最终许可证尚未确定。本阶段不对第三方资料作任何重新授权。
